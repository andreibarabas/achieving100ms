

# Achieving 100ms

💻 Código fuente de la serie de TikTok ["Achieving 100ms"](https://www.tiktok.com/@achieving100ms).

## ¿Por qué 100ms?

`100ms` es el Santo Grial del desarrollo de productos, ya que proporciona la experiencia definitiva para las personas que lo utilizan.

Según el [Estudio de Ingeniería de Usabilidad (1993)](https://www.nngroup.com/articles/response-times-3-important-limits/), `100ms` es aproximadamente el límite para que el usuario sienta que el sistema está `reaccionando de forma instantánea`, lo que significa que no es necesario un feedback especial más que mostrar el resultado.

A continuación, puedes encontrar una lista de consejos y trucos que pueden ayudarte a alcanzar ese objetivo.
